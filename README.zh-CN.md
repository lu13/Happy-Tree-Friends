# Happy Tree Friends

[English](README.md) | [简体中文](README.zh-CN.md)

Happy Tree Friends 是一款适用于 **《魔兽世界》正式服 12.1** 的轻量日常工具合集。它将安全的团队减益增强、商人自动化、可定制角色属性悬浮层和友方姓名显示整合在一个简洁的独立设置窗口中。

## 主要功能

- **自动修理** — 可选择使用角色金币或公会资金修理装备。
- **自动售卖垃圾** — 与商人交互时自动出售灰色品质物品。
- **垃圾物品保护** — 按物品链接或物品 ID 保护指定灰色物品，避免误售。
- **本次登录账本** — 查看本次登录期间的修理支出、售卖收入和跳过的保护物品。
- **冒险状态悬浮层** — 在透明悬浮层中显示角色属性、耐久度、背包空位、金币和延迟；支持移动、缩放和锁定。
- **灵活显示样式** — 每项内容均可独立显示或隐藏，并可调整字体大小和颜色。
- **友方仅姓名** — 隐藏友方玩家姓名板杂项，仅显示姓名，并支持自定义字号。
- **团队减益增强** — 保持暴雪“只显示可驱散减益”设置不变，同时在小队和团队框架上按类别额外显示流血、控制、团本重点和短时其他减益，每类最多 2 个。
- **紧凑光环控制** — 可独立开关四类减益、在 8–24 像素间调整图标大小、选择框架四角位置，并微调图标偏移。
- **独立设置窗口** — 输入 `/htf` 直接打开简洁、可移动的 HTF 设置窗口。
- **本地化与诊断** — 支持简体中文和英文，并提供可选调试日志及可复制的诊断报告。

## 命令

- `/htf` — 打开设置窗口。
- `/htf stats` — 打开属性悬浮层设置。
- `/htf merchant` — 打开商人功能设置。
- `/htf nameplates` — 打开友方姓名设置。
- `/htf debuffs` — 打开团队减益增强设置。
- `/htf protect <物品链接或物品 ID>` — 保护灰色物品，防止自动出售。
- `/htf unprotect <物品链接或物品 ID>` — 取消物品保护。
- `/htf protected` — 查看已保护物品。
- `/htf debug` — 开启或关闭调试模式。
- `/htf dump` — 生成可复制的诊断报告。
- `/htf clearlog` — 清空已保存的调试日志。

## 兼容性

- 简体中文与英文

## 团队减益限制

WoW 12.1 无法可靠地按法术 ID 筛选友方单位身上的有害光环，因此本插件使用暴雪提供的流血、控制和战斗中团队重点安全分类，并以互斥的“短时其他”分类兜底显示最长 60 秒、当前角色“只显示可驱散”过滤未覆盖的其余减益。该兜底可覆盖乌拉特克的步履维艰（法术 1300938），但也可能包含并非移动减速的短时效果。
